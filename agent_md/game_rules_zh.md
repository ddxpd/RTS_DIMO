# IRON FRONT 游戏规则总结（中文）

> 状态：2026-09-20 当前构建；数值以 simulation.gd 常量为准。

## 一、游戏模式与胜负
- 单人 vs AI；或局域网主机-客户端（主机权威模拟，20Hz，最多 4 客户端，快照 20Hz + guest 外推平滑）
- 胜负：一方**所有建筑**被摧毁即判负；双方同时全灭为平局
- 分出胜负后模拟冻结，仅可重开/回标题

## 五、生产与集结
- 生产绑定：兵营=士兵、矿场=矿车、基地不生产
- 兵营/矿场右键设集结点（R 标记），新单位出生即前往
- 矿车无集结点→自动去最近**可见**金矿

## 六、战斗与移动
- 右键：地面=移动 / 敌人=攻击 / 矿=采集；A=攻击模式（可强制友军）
- 士兵射程内自动索敌；单位碰撞分离；A* 寻路（障碍绕行、拐角侧步）
- 相向单位右侧让行形成双向车道，避免对撞死锁

## 七、视野
- 单位/建筑提供半径 **340** 视野；迷雾每 0.2s 刷新；探索地形保留记忆
- 地堡只打可见敌人；矿车只去可见矿

## 八、AI 逻辑（单人对手）
- **经济优先**：建矿场 → 产满 5 矿车 → 建兵营 → 持续产兵（队列≤2）→ 富余 $1200 时在基地旁建地堡
- **防御优先于进攻**：敌单位进入己方建筑 600px 内时，最多 6 名士兵拦截
- **小队战术**：不足 6 名士兵时在基地旁集结（-192px）；满 6 名后以攻击移动扑向**最近的敌方建筑**（不再排队直冲基地），途中自动交战

## 九、操作
- 左键选择/拖框（HUD 上松开也能完成）；双击选屏幕内同类；空白清除
- 编队：Ctrl+数字=建组（可含建筑），Shift+数字=追加，数字=召回（单位优先）
- S 停止 / A 攻击 / B 兵营 / Esc 菜单
- 底部三区：MAP 预留 / STATUS 状态区（单位缩略图名册 兵/矿 + 缩略图生产队列 + 进度条）/ COMMAND 指令区（SC2 式同卡命令区）；缩略图当前为占位中文字，后续替换为图片

## 十、镜头
- 四向边缘滚动均以**窗口物理边缘**触发（32px）；WASD/中键/滚轮锚定缩放
- 动态最小缩放保证镜头可移动；世界边缘钳制；窗口模式鼠标锁定
- Camera speed：0.5x–3.0x，默认 1.4x，持久化 user://settings.cfg；攻击键可重绑

## 十一、开局配置
- 双方各 **6 士兵、0 矿车**（单列纵队贴基地右侧）；基地蓝 (384,384) / 红 (4416,2816)
